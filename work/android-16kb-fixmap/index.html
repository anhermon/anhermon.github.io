What was built

Product, data method and sign-off: Angel. Measurement scripts, page generator, copy and QA: AI-agent pipeline; the page says so on its face.

The opposite brief to the concepts: a utilitarian data site where the design job is scanability, trust and a clear free-to-paid step. It is plain on purpose.

  • A generator that downloads the published artifacts of 80 Android native libraries and measures the ELF alignment of each .so file
  • 80 library pages and an index, built statically from the dataset
  • A deadlines section at the top (targetSdk 36, Billing Library 7, the 16 KB page-size rule), with a countdown and a page per exact Play warning
  • A free dependency-free checker script and a paste-your-dependencies page
  • A paid kit with hosted checkout, and a double opt-in watch form that stores only an email, the library ids and the consent wording
  • A 'Deliberately not claimed' section listing what was not measured

Stack Python generator, static HTML, Cloudflare Pages, a small Cloudflare Pages Function and D1 for the watch form

Decisions, with the reasons.

Data

The headline number is a count you can check

The title says how many libraries were measured (80). Under the Play warnings and deadlines, the table is split by outcome in the order a developer needs: 63 fixed by upgrading, 11 with no aligned release yet, 4 where the native code was removed, 2 relocated to another artifact. Each row names the exact artifact and the version to move to.

Approach

A section for what is not claimed

Four items the data does not cover (a private-Maven SDK, an editor-bundled engine, a media decoder set, React Native app builds) are listed on the page with the reason. Limits stay visible next to the paid offer instead of being buried. The footer says the pages were generated by a script, AI-assisted, with numbers measured and not copied from release notes.

Rejectedpadding the count with libraries that were not downloaded and measured.

Interaction

From free answer to paid kit

The free tier is the whole table, the in-browser checker and the checker script. A Free vs. the Kit comparison sits above the table: the kit ($12) adds the full dataset as JSON and every raw measurement, a fix guide and updated downloads, with a 14-day refund stated next to it. A watch box asks for an email and an explicit consent tick for status alerts.

How it was started Built from a measured dataset, not hand-written pages. The generator is a single script, so adding a library is a data change and every page, sitemap entry and table stays consistent.
