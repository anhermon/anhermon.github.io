What was built

Art direction and sign-off: Angel. Concept, copy, build, imagery and QA: AI-agent pipeline, reviewed page by page.

A tactile consumer direction: flat saturated colour blocks, a soft variable serif and one signature moment, where marking an invoice paid sends a clay pebble into the tax jar.

  • Single landing page, static HTML/CSS/JS, no framework
  • Phone mock-up of the product drawn in code, with an autoplaying demo
  • Clay-style renders generated with Codex image generation, then colour-matched to each flat block by a processing script
  • Jar-maths calculator, nudge and toggle micro-interactions
  • Demo form that is deliberately non-submitting

Stack Static HTML, CSS, vanilla JS, self-hosted fonts, Cloudflare Pages

Decisions, with the reasons.

Type

A variable serif with its softness turned all the way up

Display is Fraunces, a variable serif with SOFT and WONK axes. Headlines run SOFT 100 so the terminals read as rounded, tracked at -0.02em and set at line-height 1.14 (it was 1.04 until a descender collision between two heading lines was found in review). Body is Figtree. Both are self-hosted woff2 subsets, so there is no third-party font request.

Rejecteda geometric sans. It is what every fintech page already uses and gave the concept nothing to be remembered by.

Colour

Four saturated blocks on cream, never gradients

Colour is applied as flat blocks of coral, butter, sage and lilac on a warm cream, with a dark brown ink instead of black. Each of the three habits owns one block, so colour carries meaning instead of decoration.

Rejectedscalloped section edges (as seen on one reference). They fought with the already round card radii.

Interaction

Signature interaction: mark paid, watch the pebble drop

In the phone demo, marking an invoice paid animates a clay pebble into the tax jar, updates the ring and the running total, and plays once on load. The jar-maths slider below lets a visitor move an invoice amount and watch the set-aside change. Illustrative arithmetic only, labelled as such on the page.

How it was started Seven reference sites were measured first (computed type scale, spacing, radius, motion timing) and the numbers drove the build: giant tight display type at line-height 0.85-0.9 on the references, 44-72px pill buttons, radius 24 and up, 0.15-0.35s eased transitions, 96-128px section padding.
