What was built

Art direction and sign-off: Angel. Concept, copy, build and QA: AI-agent pipeline, reviewed page by page.

A blueprint direction: a cobalt drawing sheet, condensed stencil numerals and one signal orange reserved for stamps, gates and removed lines. Its signature is a pinned scene where an exploded pipeline is built up as you scroll and a ticket travels through it.

  • Single-page launch concept, static HTML/CSS/JS, no framework
  • Pinned scroll scene: an isometric exploded pipeline in which a ticket travels through five stages
  • Every figure drawn in code (SVG generated by a build script); no stock or generated imagery
  • Flight-recorder panel: scrub a sample run and inspect its spans, all labelled as sample data
  • Budget and approval-gate demo, and an interest form that is deliberately non-submitting

Stack Static HTML, CSS, vanilla JS, SVG generated by a build script, self-hosted fonts, Cloudflare Pages

Decisions, with the reasons.

Type

A condensed display face, as on a title block

Big Shoulders Display carries headlines and the numerals, Azeret Mono labels and data, and Archivo sets body copy. Mono appears only where the page shows data or drawing annotations, the way a drawing sheet does. All three are self-hosted woff2 subsets.

RejectedInstrument Sans with Sometype Mono. Those are Halcyon's faces; each concept should own its type.

Colour

One orange, kept for what is wrong or gated

Ink, cobalt and a pale drawing-line blue make the sheet. Cyan highlights live data. The signal orange is used only for stamps, approval gates and removed lines, so when it appears it means a decision or a defect.

Interaction

Signature interaction: a pipeline that builds as you scroll

A pinned scene shows an isometric exploded pipeline. Scrolling steps through ticket, router, runner, approval gate and pull request, and the ticket travels the stack while a flight-recorder trace builds beside it. Below it, the recorder, a budget meter and an approval gate can all be operated; every figure on them is sample data.

How it was started Six reference sites were measured first (Linear, Axiom, Langfuse, Honeycomb, OpenTelemetry, teenage engineering). Takeaways: tight display line-height around 1.0, dense 14-15px body, mono only for data, and spec-sheet density, which led to the drawing-sheet direction rather than another dark SaaS look.

Honest limits.

  • A concept: Draughtwell does not exist. The name is a placeholder; a trademark search was not possible.
  • Mobile is the weaker side: the large drawings become a stepper on narrow screens, and the independent critic scored the mobile layout below the desktop one.
  • Lighthouse SEO is 63 because the preview is deliberately noindex, not because of a page fault.
  • Two of the parts on the parts list are real open-source projects of mine; the rest are drawn and labelled as design goals.
